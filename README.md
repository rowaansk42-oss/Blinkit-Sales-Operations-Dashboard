# 🛒 Blinkit Sales & Operations Dashboard

An interactive Excel dashboard built using **Microsoft Excel, Power Query, Pivot Tables, Pivot Charts, and Slicers** to analyze Blinkit retail sales and operational performance.

---

## 📌 Project Overview

This dashboard helps analyze retail business performance by providing insights into:

- Total Sales
- Total Orders
- Total Quantity Sold
- Average Order Value
- Monthly Sales Trend
- Sales by Category
- Top 10 Products
- Payment Method Distribution
- Delivery Status Analysis

The dashboard is fully interactive using slicers for dynamic filtering.

---

- Microsoft Excel
